# Automate the Boring Stuff with Python: exercises and projects

Scripts written while working through *Automate the Boring Stuff with Python* by Al Sweigart, along with the earlier *Python Crash Course* basics, during my SIWES II training.

## Highlights

| Topic | Where to look |
|---|---|
| Regular expressions | `regex.py`, `isPhoneNumber.py`, `phoneAndEmail.py` (phone and email extractor), `strongPassword.py`, `regexsearch.py` |
| Files and folders | `files.py`, `backupToZip.py` (numbered ZIP backups), `selectiveCopy.py`, `findBigFIles.py`, `renameDates.py`, `organizingFiles.py` |
| Clipboard tools | `mcb.pyw` (multi-clipboard), `bulletPointAdder.py`, `pw.py` (demo password locker using the book's sample values) |
| Quizzes and text | `randomQuizGenerator/`, `madlibs.py`, `fillTheGaps.py`, `addGaps.py` |
| Debugging | `debugging/` (assertions, logging, tracebacks) |
| Web scraping | `webScraping/` (requests, BeautifulSoup, Selenium) |
| Excel, Word and PDF | `workingWithExcelSpreadsheets/`, `workingWithPdfsAndWordDocuments/` |
| CSV and JSON | `workingWithCsvAndJsonData/` |
| Images | `makingGraphsAndManipulatingImages/` (Pillow) |
| Time, scheduling, launching programs | `keepingTimeSchedulingTasksAndLaunchingPrograms/` |
| Email and notifications | `automatingEmail/` |
| GUI automation | `guiAutomation/` (PyAutoGUI) |
| Text in images and speech | `recognizingTextInImages/`, `speechRecognitionEngines/` |
| Python Crash Course basics | `name_function.py`, `test_name_function.py`, `survey.py`, `test_survey.py`, `remember_me.py`, … |

## Notes

- Downloaded files, generated images, videos and the book's own online materials are not included, only my code and small sample data files.
- The email scripts need your own Gmail API `credentials.json` and `token.json`. These are personal secrets and are deliberately not in this repository.
